What It Is

A resident,
not an app.

One system on your machine, tuned to you.

Substrate is a source-available agentic system that turns your machine from an inanimate silo into something conversational, proactive, and autonomous. It is model-independent by design — pair it with an OpenRouter key and it loads any model online, run entirely offline through your preferred model library, or take a hybrid approach with both. It learns your patterns and remembers your context, adapting into a uniquely tuned agent specific to each user. One foundational substrate, infinite potential outcomes.

A resident, not an app

It reads and writes files, runs commands, browses the web, and runs scheduled jobs — then reports back in plain language.

It works while you're away

Give it a goal and it plans, acts, and verifies on its own — chaining tools across steps, recovering from errors, and asking only when a decision is genuinely yours.

Voice or text, with memory

Talk or type — it replies in text and can read every answer aloud. Everything it learns persists between sessions, so it knows your projects, preferences, and past work.

What It Can Do

Twelve things
it does today.

Every line below runs in the current build.

Files

Reads and writes your files

Opens, searches, edits, and creates files and folders anywhere you point it. Surgical find-and-replace, not whole-file rewrites.

Shell

Runs commands

PowerShell, CMD, or Bash — installs packages, runs scripts, reads the output, and acts on what came back.

Browser

Drives a real browser

Navigates, clicks, types, fills forms, reads pages, and takes screenshots through Chrome DevTools — its own window, not yours.

Desktop

Controls the desktop

Moves the mouse, types, reads window contents, launches apps, and handles dialogs — for the software that has no API.

Web

Searches and fetches

Searches the live web and pulls full pages down as readable text, with the sources it used.

Memory

Remembers across sessions

Stores facts and searches past conversations. Close the app, come back a week later, it still knows the project.

Schedule

Works on a clock

Recurring jobs run on their own — overnight research, morning briefings, standing checks — and report when they're done.

Voice

Talks and listens

Speech in, speech out. Ask out loud, get an answer read back. Text input works the same way.

Documents

Reads PDFs

Extracts text, searches inside long documents, and pulls metadata — then works with what it found.

Images

Generates images

Creates visuals from a prompt through Flux, DALL·E, or Imagen, and saves them where you asked.

Delegation

Spawns sub-agents

Splits work across background agents that run in parallel, then collects what each one returns.

Repetition

Saves what it learns

Turns a working procedure into a macro or skill, so the same job runs the same way every time after that.

Day to Day

What it actually
does for you.

Not a feature list. Four things that happen on a normal day.

06:40 — before you're up

It already did the reading

A scheduled job runs at 8:00. It searches, opens sources, checks them against each other, and leaves three stories drafted and waiting — with the links it actually visited.

09:15 — you're mid-project

It works in your files

Point it at a folder and ask for the change. It reads before it writes, keeps the edits small, and tells you which files it touched so you can check the diff yourself.

14:00 — something's broken

It goes and looks

Runs the command, reads the error, searches for the cause, tries the fix, and reports what it found. If it needs a decision that's yours, it stops and asks instead of guessing.

22:30 — you're done for the night

It picks up tomorrow

Memory persists across sessions. Next morning it knows what you were building, what broke, and what you decided — without being told again.
